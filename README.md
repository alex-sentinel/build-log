# build-log

This is everything I write down while building Hernandez Systems Group.
All my finished projects and failures will be documented here.

## What's in here

- **builds/** — the process of building each project once it's actually shipped: what I built, why I built it, what broke, whats next.
- **bug-journal/** — my personal record of failures I hit, I write these as they happen
- **concepts/** – things I learned that aren't tied to a project. things I can explain later on
