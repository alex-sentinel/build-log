# build-log

This is everything I write down while building Hernandez Systems Group.
Finished projects and raw failures will be documented here.

## What's in here

- **builds/** — my process of building each project once it's actually shipped: what I built, why I built it, what broke, whats next.
- **bug-journal/** — my personal record of walls I hit, I write these when they happen
- **concepts/** – things I learned that aren't attached to a project. things I can explain later
