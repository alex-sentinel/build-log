# hernandezsg.com
Portfolio site for Hernandez Systems Group

A static site that is built in Astro and deployed on Cloudflare pages. 
I designed the site in Claude Code, by making a prompt that specified the layout, copy, and stack. Claude Code generated the site and I made sure it was good by improving the copy before pushing it.

This is so that I have somewhere to direct people to when I am reaching out. The point is to show what I have delivered to real clients, not just a form that says I do web work. 

The site includes a hero, a case study, a section that specifies what I build, and a contact button. It has a white background with a dark green style.

After committing what Claude Code had built, I made a repo on GitHub, and connected that repo through Claude Code. Then I connected Cloudflare pages to the GitHub repo through the dashboard. I set it up so that each push to ```
```main deploys automatically. The domain is ```hernandezsg.com``` which was registered on Cloudflare so the domain connected by itself.
